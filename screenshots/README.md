# Screenshot Evidence Checklist

Save genuine screenshots in this directory.

Recommended screenshots:

1. SOME/IP daemon running successfully.
2. Vehicle Speed Service Provider running.
3. Instrument Cluster Consumer showing a successful GetSpeed response.
4. Consumer displaying SpeedChanged notifications.
5. Project directory and source files.
6. Wireshark/TShark showing captured SOME/IP request and response packets.
7. Wireshark/TShark showing SpeedChanged event packets, after verified.

Suggested filenames:

- daemon_running.png
- provider_running.png
- consumer_response.png
- speed_changed_events.png
- project_files.png
- wireshark_request_response.png
- wireshark_events.png

Only save screenshots that actually show the described result. The final two packet-analysis screenshots must wait until the corresponding packets have been captured and verified.
